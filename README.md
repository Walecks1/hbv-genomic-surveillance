# HBV Genomic Surveillance & Molecular Epidemiology

## Project status

Phase 1 — Dataset discovery and project design

## Overview

This project is my attempt to develop a documented reproducible bioinformatics workflow for
whole-genome hepatitis B virus (HBV) sequencing data. It can be adapted to other similar pathogens

The workflow will progress from raw sequencing reads through:

- quality control
- read preprocessing
- genome reconstruction
- variant analysis
- genotype analysis
- phylogenetics
- molecular epidemiological interpretation

The final project will integrate the analysis into a reproducible
workflow and an interactive data visualisation layer.

## Scientific question

How reliably can a reproducible whole-genome sequencing workflow
reconstruct HBV genomes and resolve viral genotype structure from
Illumina short-read data?

## Current phase

### Phase 1 — Dataset discovery and selection

Current objectives:

- identify suitable public HBV sequencing datasets
- evaluate dataset provenance
- establish inclusion and exclusion criteria
- select the primary dataset
- document the selection decision

## Reproducibility

The project is being developed using version control and will
progressively incorporate workflow automation, testing and
environment management.
